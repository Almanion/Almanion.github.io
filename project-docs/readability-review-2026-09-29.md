# Цвета и читаемость конспектов

29 сентября 2026 года

## Вывод

Основной текст текущей «Призмы» уже хорошо контрастирует с фоном. Полностью менять палитру не требуется. Первое полезное изменение — сделать контрастнее бледные подписи, сохранив светлую и тёмную темы на выбор.

## Что говорят исследования

- Piepenbrock, Mayr, Buchner (2014), *Smaller pupil size and better proofreading performance…*: в эксперименте с корректурой тёмный текст на светлом фоне давал лучшие результаты, чем светлый на тёмном. Это результат конкретной зрительной задачи, а не доказательство того, что тёмная тема вредна или всегда хуже. [Исследование](https://pubmed.ncbi.nlm.nih.gov/25135324/).
- Их отдельное исследование *Positive display polarity is particularly advantageous for small character sizes* сравнивало четыре размера текста. Преимущество светлого фона увеличивалось при уменьшении символов. Для конспектов это довод не делать мелкими подписи и формулы, особенно в тёмной теме. [Исследование](https://pubmed.ncbi.nlm.nih.gov/25141597/).
- WCAG 2.2 требует для обычного текста контраст не ниже 4,5:1, для крупного — 3:1. Это стандарт доступности, а не исследование предпочтений. [W3C](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

## Проверка текущих цветов

Расчёт по относительной яркости sRGB: `(Lсветлый + 0,05) / (Lтёмный + 0,05)`. Значения взяты из `style-new.css`, вариант «Призма». Проверены пары непрозрачных цветов на поверхности карточки; это не полный аудит всех состояний интерфейса, прозрачностей и цветных меток.

| Текст | Светлая карточка `#ffffff` | Тёмная карточка `#16161f` |
|---|---:|---:|
| Основной | `#16161f` — 17,97:1 | `#ececf4` — 15,29:1 |
| Второстепенный | `#51526b` — 7,58:1 | `#a2a2b8` — 7,18:1 |
| Бледный | `#9a9ab0` — 2,75:1 | `#6f6f86` — 3,67:1 |

Основной и второстепенный текст проходят порог 4,5:1. Бледные цвета не подходят для мелких содержательных подписей на этих фонах. Декоративные элементы и отключённые кнопки нужно оценивать отдельно.

## Варианты

1. **Точечная правка — рекомендую.** Оставить основные цвета. Для содержательных бледных подписей использовать, например, `#73738b` на белом (4,61:1) и `#85859c` на тёмной карточке (4,99:1). Проверить отдельно их контраст на остальных поверхностях. Цвета типов блоков оставить в метках и границах, основной текст — нейтральным.
2. **Дополнительный режим «Бумага».** Светлый фон с чуть тёплым оттенком, тёмный текст, минимум цветных заливок. Это предложение для спокойного чтения, не «научно лучшая» палитра. Проверить на длинных конспектах с пользователями перед изменением настроек по умолчанию.
3. **Повышенный контраст.** Отдельная настройка для подписей и элементов управления. Не делать автоматически весь текст чисто белым на чисто чёрном и не отнимать возможность выбрать тему.

Глобальные цвета в рамках этой задачи не менялись: сначала предложены варианты. Для печати используется отдельная светлая палитра, независимо от темы и масштаба экрана.
