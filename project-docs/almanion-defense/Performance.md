# Проверка плавности переходов

13 октября 2026. Microsoft Edge через Playwright, окно 1920 × 1080.
Сравнение на одном компьютере: обычный процессор и замедление 3× через CDP.
Каждый маршрут стартует из восстановленного состояния; время анимаций задано
сценарием и не ускорялось ради результатов. Скрипт: `source/animation/profile-transitions.cjs`.

Изменения:

- Для общих влётов используются две постоянные скрытые страницы. Их стили и
  шрифты загружаются заранее; перед движением копируется актуальное состояние.
- Раскрытие окна использует масштабирование слоя; конспект внутри сохраняет
  постоянный размер во время полёта.
- Растровый фон главной кодируется асинхронно без очереди кадров. Поздний
  результат не может перезаписать остановленное состояние. Во время полёта
  скрытый фон не перерисовывается; внешние звёзды продолжают движение.
- Готовый неподвижный фон повторно используется без копирования каждый кадр.
- Сброс прокрутки обращается только к двигавшимся контейнерам.
- При смене темы чтение итоговых цветов отделено от записи стилей.
- График FSRS сохраняет SVG-оси и рассчитанные кривые; обновляются маркер,
  область раскрытия и показания. Формула и числовой пример прежние.

P95 — длительность, которую не превысили 95% измеренных кадров. Меньше — лучше.
Все значения ниже: **до → после**, миллисекунды. Отчёты не являются обещанием
той же частоты кадров на другом компьютере. Начальная подготовка страниц включена
в замер. На замедленном CPU остаются отдельные задержки, особенно при настоящей
перестройке вёрстки конспекта и переключении темы.

## Вступление из трёх плоскостей

`intro-flight.js` использует один реальный iframe главной страницы. Его конечная
геометрия готовится до начала полёта; в цикле меняются только transform и opacity.
Текстовые плоскости также масштабируются без пересоздания DOM и без blur-фильтров.
Указатель остаётся видимым; следующая сцена не начинается автоматически.

На сборке `8739afe7bd93315d3a66d60f61298508801c6d64aa1fbf51c12c3ad5558e13c7`
проверены влёты 2850 и 3000 мс при 1920×1080 и 1366×768.
P95 отрисовки звёздного canvas: 8,8–11 мс в локальном Edge без замедления CPU.
Это время canvas, не полный бюджет кадра и не гарантия FPS другого компьютера.
Отчёт: `evidence-v2/intro-verification.json`; остановки дополнительно сравнены
попиксельно через 350 мс. Режим уменьшенного движения сразу восстанавливает
тот же конечный кадр. Переходы не создают фоновых таймеров.
