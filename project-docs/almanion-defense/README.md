# Almanion — интерактивная защита проекта

Презентация: https://almanion.github.io/presentation/

`Almanion.html` — автономная версия. Интернет и установка зависимостей не нужны.
Пробел / → — следующий шаг, ← — назад. Есть оглавление, повтор, полноэкранный
режим и настройка уменьшенного движения. Всего 33 управляемых состояния.

`Заметки-выступающего.html` содержит отдельный текст выступления.
Числовой пример FSRS фиксирован на 12 октября 2026 года; материалы и библиотека
в `source/reference/` соответствуют версии `f7f708a3b7266700b8a9ce2df9070e681e875654`.

Исходники демонстрации: `source/animation/`. Сборка:

```powershell
node project-docs/almanion-defense/source/animation/build.cjs
node project-docs/almanion-defense/source/animation/notes.cjs
```

Проверки используют Playwright и Microsoft Edge. Публикуемый файл находится
в `presentation/index.html`; он должен совпадать с автономным `Almanion.html`.
Сборка GitHub Pages допускает к публикации только готовый HTML из этой папки.

Первые пять действий образуют маршрут: выбор 10 класса → влёт в физику →
раздел 1.6 → формула → поиск по другой теме. Курсор плавно тормозит у цели,
перед нажатием выдерживает короткую паузу и затем освобождает текст.
Точки остановки привязаны к реальным элементам страницы и одинаково
восстанавливаются при возврате, повторе и уменьшенном движении.
Поиск оставляет текущую формулу справа: найденная тема открывается
отдельным следующим действием. Проверка: `source/animation/verify-first-five.cjs`.

Код Almanion извлекает карточки, организует интерфейс, очередь, подтверждения
и сохранение состояния. Математический планировщик FSRS‑6 — библиотека
Open Spaced Repetition; её лицензия включена в HTML и `source/reference/`.

Автономный HTML содержит обе демонстрационные страницы, шрифты, изображения
и FSRS, поэтому для него задан отдельный бюджет 5 МБ. Исходники и результаты
проверок в project-docs не входят в сайт и исключены из бюджетов доставки.

Оптимизация переходов и измерения до/после описаны в [Performance.md](Performance.md).
Скрипт сборки обновляет автономный HTML и опубликованную копию одновременно.

После поиска и настроек добавлены три остановки о регистрации: вход,
форма создания аккаунта, личный профиль и схема синхронизации. Формы
получены из настоящего `account.js` ревизии `e727813`; Firebase в показе
не запускается. Пояснение синхронизации визуально отделено от интерфейса.
Сценарий: `account-scenes.js`; проверка: `verify-account.cjs`.
