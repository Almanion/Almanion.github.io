# Конспекты из конструктора

Каждый предмет хранится в собственной папке:

- `manifest.json` задаёт порядок опубликованных разделов;
- `sections/<id>.json` содержит один верхнеуровневый раздел вместе с его
  подразделами и вложенными блоками.

Исходные HTML-страницы остаются обычной статикой. Во время GitHub Pages deploy
скрипт `tools/build-notes.js` читает JSON и вставляет готовую разметку между
маркерами `NOTE_CONSTRUCTOR_*`. Поэтому поиск, закладки и режим последовательного
чтения работают с новыми разделами так же, как со старыми.

Не редактируйте автоматически сгенерированную разметку в `_site`: она создаётся
заново при каждой публикации. Ручные старые разделы и JSON-разделы могут
сосуществовать на одной странице.
