# Almanion.github.io — конспекты и материалы

Веб-сайт с материалами по предметам (в т.ч. 9 класс) и задачами МатЦентра.

## Разделы

- Конспекты по физике, алгебре, геометрии, химии
- Мини-проекты и отдельные страницы (например, «Мёртвые души» — каталог в `dead souls/`)

## Структура репозитория

- **Корень** — статика сайта: `index.html`, страницы предметов, `script.js`, папки `styles/`, `matcenter/`, `images/`, `dead souls/` и т.д. Для репозитория `username.github.io` GitHub Pages обычно отдаёт файлы из **корня** ветки `main`.

- **`matcenter/`** — модули страницы МатЦентра: ядро, безопасность, авторизация, загрузка данных, личный прогресс, рендеринг, навигация/поиск и подсказки.

- **`styles/site/`** — разделённые слои бывшего монолитного `style.css`; `index.css` сохраняет их исходный каскад.

- **`content/`** — конспекты, созданные через `constructor.html`: манифест предмета и отдельный JSON-файл для каждого нового раздела. При публикации GitHub Actions встраивает эти разделы в существующие HTML-страницы.

- **`images/notes/`** — изображения новых конспектов. Конструктор добавляет их в тот же атомарный commit, что и текст раздела.

- **`docs/`** — вложенный репозиторий Git (подмодули; отдельная рабочая копия/история). Не смешивать с настройкой «папка `docs/` в Pages»: на GitHub сейчас публикуется **корень** этого репозитория.

- **`Local/`** — локальные заметки, скрипты и бэкапы; на сайт напрямую не рассчитано.

## Технологии

HTML, CSS, JavaScript; для формул — KaTeX там, где подключено на страницах.

## Инструменты чтения

- **Конспекты без сети**: в меню предмета — «Читать без сети», на главной — настройки → «Конспекты на устройстве». Загрузка включает разделы, формулы, шрифты и изображения. Пакеты проверяются по SHA-256 и хранятся отдельно от временного кеша; отмена и ошибка обновления не удаляют предыдущую копию. Частный английский и данные аккаунтов в публичные пакеты не входят. Браузер может удалить данные при очистке хранилища.
- **Личные пометки**: кнопка с карандашом у блока и общий список в меню. Без входа сохраняются на устройстве, после входа — в существующем защищённом хранилище пользователя `bookmarks/<uid>` с признаком `noteOnly`. Удаление закладки не удаляет пометку. В общий конспект, PDF и карточки обучения пометки не попадают.
- **Учебные карточки**: в редакторе блока можно исключить его из обучения, задать название карточки и выбрать обработку формул. По умолчанию промежуточные выкладки не становятся отдельными карточками, но итоговая формула вывода сохраняется.
- **Публикация**: принятие изменений GitHub отображается отдельно от готовности сайта. Конструктор проверяет содержимое опубликованного раздела без кеша и сохраняет состояние проверки при перезагрузке. Обновление правил Firebase и Apps Script для этих функций не требуется.
