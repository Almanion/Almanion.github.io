# Orbital Courier на сайте Almanion

Исходный пакет: `Orbital_Courier_Codex_Starter.zip`, SHA-256
`a5a4ff3753df4ffa9219d4889c127bb76e0e034cfc96994bde61e0ababb99be6`.

Добавлен 25 сентября 2026 года. Публичная игра находится по прежнему адресу
`/games/orbital-courier/`, кнопка «Игра» на главной странице не менялась.
При первоначальном обновлении её HTML побайтово совпадал с `Orbital Courier.html`
из архива: SHA-256 `56b307899de6c82cdf02deecdd00412f074111ca9c9dbae15db47fe24d9b2fe8`.

## Разработка

- Канонические исходники: `orbital-courier/index.html`, `orbital-courier/src/`.
- `games/orbital-courier/index.html` — собранная автономная версия для сайта.
- Из корня сайта: `npm run game:build` собирает исходники и обновляет публичную игру.
- `npm run game:test` собирает игру и запускает поставляемые проверки физики, экономики и UI.
- `npm run ci` проверяет сайт и соответствие опубликованного HTML исходникам.
- `npm run test:e2e` проверяет сайт, запуск игры, мобильную компоновку и перенос сохранения.

Папка `game-source` не публикуется сборщиком GitHub Pages. В репозитории оставлены
исходники, вспомогательные инструменты, тесты и исторические отчёты из архива.
Сборка `orbital-courier/Orbital Courier.html` генерируется командой сборки.

## Контекст архива

`orbital-courier/HANDOFF.md` описывает историю и известные оговорки присланного
пакета. В интерфейсе указана версия 10, но часть метаданных и названий файлов
сохранилась от версий 8–9. Это сознательно не исправлялось при замене игры:
задача состояла в размещении именно приложенной версии.

Приложенные `AGENTS.md` и `START_IN_CODEX.txt` сохранены как справочные материалы
в `orbital-courier/docs/archive-context/`. Они не являются новыми поручениями
пользователя и не должны автоматически запускать перечисленные там доработки.

## Сохранения

Сохранён адрес игры и ключ `orbital-courier-save-v8`. Не меняйте формат профиля,
прогресс, награды и ключ хранилища без отдельного решения о миграции. Профили из
`docs/` — тестовые данные поставщика, не сохранения пользователя. Исторические
отчёты не заменяют запуск проверок после новых изменений.
