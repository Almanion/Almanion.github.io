ОРБИТАЛЬНЫЙ КУРЬЕР / 10.1

На связи, пилот.

Карта перед глазами. Курс под контролем.

Обновлённый интерфейс для телефона, планшета и компьютера. 80 контрактов выстроены в пять ступеней: начальная, средняя, сложная, экспертная и предельная. Вместо многоадресных рейсов — четыре новые карты «Предела навигации». Старые рекорды и награды сохранены.

В настройках управления можно выключить звук или изменить громкость. Груз, кольцо, облёт и портал звучат по-разному; при паузе гул полёта затихает.

Запуск без установки

  1. Распакуй ZIP целиком в обычную папку.
  2. Открой Orbital Courier.html браузером. На Windows можно нажать PLAY.bat.
  3. Выбери контракт и настрой угол и скорость. Нажми «Запуск».

Обычный запуск не требует Node.js, Python или подключения к интернету. Отдельный файл Orbital_Courier_9.html содержит ту же игру. Не запускай её внутри ZIP или предпросмотра вложений.

Перенос без потери прогресса

Сначала экспортируй JSON в старой игре. Настройки → Прогресс → Экспорт. Затем в новой: Настройки → Прогресс → Импорт, выбрать файл и подтвердить замену.

Баланс, опыт, модули, чеки, условия медалей и постоянные курсы A/B не пересчитываются. Схема JSON намеренно остаётся version: 8, хотя версия приложения — 9. Незаконченный рейс, масштаб карты и временная история полётов не экспортируются.

Автосохранение зависит от браузера и адреса игры. При переименовании HTML, переносе папки или смене браузера оно может не подхватиться. Оранжевый ! в игровом заголовке означает, что хранилище недоступно; нажми на него для перехода к экспорту. Экспорт не является облачной синхронизацией. Храни JSON отдельно от игры.

Управление на телефоне

Карта открывается в режиме «Курс»: укажи пальцем, куда должен стартовать курьер. Можно коснуться нужной точки или вести палец. Чем дальше палец от курьера, тем сильнее старт. Для перемещения карты одним пальцем выбери «Обзор». В очень низкой альбомной компоновке эти режимы доступны через ⋮ у карты.

Управление на компьютере

В режиме «Курс» потяни мышью в направлении полёта. В режиме «Обзор» перетаскивание меняет только камеру. Alt + мышь или средняя кнопка временно включает обзор. Колесо увеличивает точку под указателем; Ctrl + колесо оставлено браузеру.

Где что находится

Медали над картой. Короткая строка показывает прогресс, нажатие раскрывает условия. На совсем низких экранах медали доступны через меню «…» контракта.

«Дальше» над картой. Открывает полный план облётов, порталов и адресных доставок. Во время просмотра полёт приостановлен. Карточка ветви меняет подсветку и описание, а не физику мира.

Курсы и оснащение. На компьютере — раскрываемый раздел пульта; на телефоне — A/B внизу. «Сохранить» записывает числа, кнопка со значениями их восстанавливает. Это память параметров, не переключатель ветвей A/B.

Во время рейса. Числовые поля заменяются телеметрией. Запуск превращается в паузу. Орбиты останавливаются вместе с симуляцией; просмотр карты не меняет движение.

После рейса. Ползунок воспроизводит уже выполненный полёт. «Сравнить» накладывает предыдущую попытку, «Награды» или «Детали» открывает результат. «Изменить курс» возвращает подготовку, но не запускает повтор автоматически. История хранится только в текущем сеансе; для постоянной памяти параметров используй A/B.

Настройки. «Экран» — анимации, контраст, поле и след; «Управление» — точность и звук; «Прогресс» — резервная копия и сброс. Удаление профиля требует отдельного подтверждения словом «СБРОС».

Необязательный запуск через локальную сеть

Если телефон не позволяет удобно открыть HTML напрямую, игру можно отдавать с компьютера в своей доверенной локальной сети. Для этого способа, в отличие от обычного запуска, нужен Python 3 на компьютере.

  1. Телефон и компьютер подключить к одной сети Wi-Fi.
  2. На компьютере открыть PHONE SERVER.bat или выполнить python start_server.py --lan из папки игры.
  3. Открыть на телефоне напечатанный адрес вида http://IP-КОМПЬЮТЕРА:8765/Orbital%20Courier.html.
  4. Разрешать доступ брандмауэра только для частной сети. Не пробрасывать порт роутера в интернет.
  5. После игры остановить сервер Ctrl+C. Для переноса на другой адрес заранее экспортировать JSON.
Локальный сервер не имеет пароля, шифрования и облачного профиля. Он отдаёт файлы своей папки — не клади туда личные документы. Его не нужно публиковать в интернете.

Для запуска только на компьютере есть LOCAL SERVER.bat или python start_server.py: адрес фиксирован, сервер слушает только этот компьютер. Браузерный запуск HTTP в проверочной среде ограничен политикой Chromium; реальное сетевое подключение телефона не проверено.

Если что-то не работает

Не двигается курс пальцем? Проверь режим «Курс» вместо «Обзор» и что полёт ещё не начался.

Пропал весь мир? Нажми «Вся карта». На низком альбомном экране названия сокращаются, но кнопка остаётся.

Первая кнопка не запускает? Если вводилось число, она завершает ввод. Нажми запуск ещё раз.

Нет прогресса? Импортируй резервный JSON из прежней игры. Не сбрасывай исходный профиль до проверки переноса.

Плохая плавность? Включи «Меньше анимаций» и отключи поле тяготения. Эта настройка не упрощает физику уровня.

Полный экран запрещён? Продолжай в обычном окне; на компьютере можно использовать штатный полноэкранный режим браузера.
