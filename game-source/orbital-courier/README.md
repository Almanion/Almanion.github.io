# Орбитальный курьер 10.2 — страницы и свободная кампания

Готовая офлайн-игра: 76 контрактов, 19 секторов, 93 достижения. Кампания разделена на пять ступеней сложности; вместо многоадресного блока создан «Предел навигации». Обновлены звук, астероиды и все хвосты. Численная физика и цены модулей сохранены. Подробности и метод проверки сложности — в [описании переработки](docs/CAMPAIGN_REWORK.md).

В ангаре девять моделей корабля с цельными корпусами и 11 разных следов. Раздел «Скины и следы» позволяет независимо сочетать модель, окраску и след, примерять закрытые варианты и применять доступные за накопленный XP. Опыт не расходуется; выбор сохраняется локально и в облаке. Внешний вид одинаков в ангаре, полёте, главном меню и финальном кадре стыковки. На корпусах нет номеров. Старые сохранения получают модель «Курьер» без изменения прогресса и ресурсов.

## Страницы сайта
Главная, контракты, ангар, награды и полёт имеют отдельные адреса. Раздел можно открыть напрямую, перезагрузить или вернуться кнопками браузера. Общие CSS/JS загружаются один раз и используются всеми страницами. Перезагрузка полёта открывает подготовку того же контракта; текущая попытка не возобновляется.

Первые четыре простых задания убраны из действующей кампании. Прежние записи и заработанные ресурсы сохраняются. Доступные задания можно проходить в любом порядке; на закрытой карточке указано условие — число доставок или конкретный предшественник. Все активные ID остаются прежними.

## Запуск без установки
Распакуйте архив полностью. Откройте **Orbital Courier.html** в браузере. На Windows можно использовать **PLAY.bat**. Не открывайте игру непосредственно из ZIP или из предпросмотра почты. Python, Node.js, аккаунт и интернет для обычной игры не нужны.

## Обновление с версии 8
В старой игре откройте Настройки → Прогресс → Экспорт. В новой импортируйте JSON и подтвердите замену. Баланс, опыт, оборудование, чеки, медали и A/B сохраняются; формат JSON остаётся **8** намеренно. Номер приложения — **10.2**. Перенос HTML в новую папку/браузер не означает автоматического переноса браузерного хранилища. Храните резервный JSON отдельно.

## Аккаунт на сайте

На Almanion можно включить облачное сохранение через кнопку облака в шапке любой страницы. Вход через Google или почту, регистрация и восстановление пароля доступны прямо в игре; используется тот же аккаунт сайта. После завершения каждого контракта результат сразу сохраняется на устройстве и отправляется в облако. При сбое связи отправка повторяется автоматически. Подключение добровольное; автономный HTML по-прежнему работает без сети. Настройка базы, перенос и разрешение конфликтов описаны в [инструкции синхронизации](docs/ACCOUNT_SYNC.md).

## Коротко об управлении
Карта имеет режимы **Курс** и **Обзор**. На телефоне по умолчанию включён курс. Коснитесь карты в нужном направлении от курьера или ведите палец: курьер стартует в сторону пальца. Чем дальше палец от курьера, тем выше начальная скорость. Два пальца меняют масштаб и положение карты. Отпускание не запускает капсулу. «Точно» уменьшает движения сенсорного прицела в пять раз и сохраняет курс при новом касании. Кнопка «Пульт» открывает ввод угла и скорости, ползунки и курсы A/B. Числовые поля убраны с основного экрана телефона. Кнопки ± можно удерживать. Ввод принимает запятую и точку. Первое нажатие запуска при активном редакторе числа завершает ввод; следующее запускает.

На компьютере: мышь задаёт курс, Alt + перетаскивание перемещает карту, колесо меняет масштаб. Кнопка «Вся карта» сбрасывает обзор. Стрелки меняют параметры; Shift — точная доводка. Пробел — запуск/пауза, R или К — повтор без подтверждения, G или П — поле. Escape закрывает панель/ставит на паузу. Во время рейса изменение курса отключено.

Следующий этап над картой открывает полный план. На телефоне A/B находится в «Пульте», на компьютере — в «Курсы и оснащение». Нажмите «Сохранить» у нужного слота, затем используйте его для восстановления. Слоты не выбирают ветвь уровня: это память чисел.

## Дополнительный сервер
`LOCAL SERVER.bat` / `python start_server.py` — необязательный локальный запуск, нужен Python 3. `PHONE SERVER.bat` / `python start_server.py --lan` открывает папку на доверенной домашней сети. Телефон и компьютер должны быть в одной сети. Не открывайте порт роутера в интернет и не помещайте личные файлы в папку сервера. После игры остановите сервер. Подробности в «Инструкция.html».

## Разработка
Экран завершения показывает фрагмент реального финального кадра у станции и открывает сводку: оценка, параметры рейса, медали, новые достижения
и фактически начисленные кредиты, данные и опыт. Повтор без улучшения показывает
нулевую доплату. Неудача и тренировка имеют отдельные состояния без наград.

«Разбор полёта» открывает карту с записью и перемоткой; после второго запуска
можно сравнить две попытки. «К итогам» возвращает ту же сводку. Просмотр записи
не пересчитывает награды. Основной результат, начисления, три медали и действия
помещаются на одном экране от 320×568, включая альбомный 568×320. Подробности
расчёта и достижения раскрываются отдельно. Основные действия остаются внизу;
пробел и стрелки прокручивают раскрытые подробности.

Шесть видов целей используют общий набор SVG-медалей: доставка, бережный импульс,
груз, точность, срок и исследование ветвей. В подготовке и итогах рисунок выбирается
по фактическому условию контракта. Векторы встроены в автономную сборку.

Исходники — src/. Шаблон — index.html. Для сборки нужен Node.js 18 или новее, внешние npm-пакеты не нужны.

```sh
node tools/build.cjs
npm test
python tests/browser_v9.py
python tests/browser_v9_edges.py
```

Браузерным тестам нужен Python, Playwright и установленный Chromium. Они используют **явное хранилище в памяти**, а не долговременный localStorage устройства. `UI9_FAST=1` пропускает только полный прогон кампании (переменная окружения задаётся способом вашей оболочки). Поддерживается системный Chromium в PATH. Подробности и результаты: docs/TEST_REPORT.md.

Экономика — `Экономика.html`; модель уровней — `docs/LEVEL_DESIGN.md`; архитектура и дизайн интерфейса — `docs/ARCHITECTURE.md`, `docs/UI_DESIGN.md`. Материалы уровней и economy-v8 именуются по версии, в которой были созданы. `docs/completed-v8-profile.json` — тестовый профиль, **не личное сохранение пользователя**; импортировать его для обычной игры не требуется.

## Ограничения проверки
Реальные телефоны, Safari, системная мобильная клавиатура и долговременное хранилище не проверялись. На 320-пиксельном экране весь большой мир мелкий — доступны увеличение и альбомная ориентация. Экспорт JSON остаётся основным способом безопасного переноса прогресса. Принудительный fullscreen может быть запрещён браузером.
