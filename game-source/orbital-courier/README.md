# Орбитальный курьер 10.1 — курьер, ангар и аккаунт

Готовая офлайн-игра: 80 контрактов, 20 секторов, 93 достижения. Это обновление интерфейса и управления. Правила версии 8 сохранены.

## Запуск без установки
Распакуйте архив полностью. Откройте **Orbital Courier.html** в браузере. На Windows можно использовать **PLAY.bat**. Не открывайте игру непосредственно из ZIP или из предпросмотра почты. Python, Node.js, аккаунт и интернет для обычной игры не нужны.

## Обновление с версии 8
В старой игре откройте Настройки → Прогресс → Экспорт. В новой импортируйте JSON и подтвердите замену. Баланс, опыт, оборудование, чеки, медали и A/B сохраняются; формат JSON остаётся **8** намеренно. Номер приложения — **10.1**. Перенос HTML в новую папку/браузер не означает автоматического переноса браузерного хранилища. Храните резервный JSON отдельно.

## Аккаунт на сайте

На Almanion можно включить облачное сохранение через кнопку «На устройстве» на главном экране. Вход использует существующий аккаунт сайта. Подключение добровольное; автономный HTML по-прежнему работает без сети. Настройка базы, перенос и разрешение конфликтов описаны в [инструкции синхронизации](docs/ACCOUNT_SYNC.md).

## Коротко об управлении
Карта имеет режимы **Курс** и **Обзор**. На телефоне по умолчанию включён курс. Коснитесь карты в нужном направлении от курьера или ведите палец: курьер стартует в сторону пальца. Чем дальше палец от курьера, тем выше начальная скорость. Два пальца меняют масштаб и положение карты. Отпускание не запускает капсулу. «Точно» уменьшает движения сенсорного прицела в пять раз и сохраняет курс при новом касании. Кнопка «Пульт» открывает ввод угла и скорости, ползунки и курсы A/B. Числовые поля убраны с основного экрана телефона. Кнопки ± можно удерживать. Ввод принимает запятую и точку. Первое нажатие запуска при активном редакторе числа завершает ввод; следующее запускает.

На компьютере: мышь задаёт курс, Alt + перетаскивание перемещает карту, колесо меняет масштаб. Кнопка «Вся карта» сбрасывает обзор. Стрелки меняют параметры; Shift — точная доводка. Пробел — запуск/пауза, R или К — повтор без подтверждения, G или П — поле. Escape закрывает панель/ставит на паузу. Во время рейса изменение курса отключено.

Следующий этап над картой открывает полный план. На телефоне A/B находится в «Пульте», на компьютере — в «Курсы и оснащение». Нажмите «Сохранить» у нужного слота, затем используйте его для восстановления. Слоты не выбирают ветвь уровня: это память чисел.

## Дополнительный сервер
`LOCAL SERVER.bat` / `python start_server.py` — необязательный локальный запуск, нужен Python 3. `PHONE SERVER.bat` / `python start_server.py --lan` открывает папку на доверенной домашней сети. Телефон и компьютер должны быть в одной сети. Не открывайте порт роутера в интернет и не помещайте личные файлы в папку сервера. После игры остановите сервер. Подробности в «Инструкция.html».

## Разработка
Исходники — src/. Шаблон — index.html. Для сборки нужен Node.js 18 или новее, внешние npm-пакеты не нужны.

```sh
node tools/build.cjs
npm test
python tests/browser_v9.py
python tests/browser_v9_edges.py
```

Браузерным тестам нужен Python, Playwright и установленный Chromium. Они используют **явное хранилище в памяти**, а не долговременный localStorage устройства. `UI9_FAST=1` пропускает только полный прогон кампании (переменная окружения задаётся способом вашей оболочки). Поддерживается системный Chromium в PATH. Подробности и результаты: docs/TEST_REPORT.md.

Экономика — `Экономика.html`; модель уровней — `docs/LEVEL_DESIGN.md`; архитектура и дизайн интерфейса — `docs/ARCHITECTURE.md`, `docs/UI_DESIGN.md`. Материалы уровней и economy-v8 именуются по версии, в которой были созданы. `docs/completed-v8-profile.json` — тестовый профиль, **не личное сохранение пользователя**; импортировать его для обычной игры не требуется.

## Ограничения проверки
Реальные телефоны, Safari, системная мобильная клавиатура и долговременное хранилище не проверялись. На 320-пиксельном экране весь большой мир мелкий — доступны увеличение и альбомная ориентация. Экспорт JSON остаётся основным способом безопасного переноса прогресса. Принудительный fullscreen может быть запрещён браузером.
