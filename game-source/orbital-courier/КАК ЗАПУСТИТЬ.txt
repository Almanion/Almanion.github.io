ОРБИТАЛЬНЫЙ КУРЬЕР 9

1. Распакуйте всю папку из ZIP.
2. Откройте Orbital Courier.html в браузере (или PLAY.bat на Windows).
3. На телефоне карта по умолчанию в режиме ОБЗОР. Для прицеливания выберите КУРС.
4. Полная инструкция: Инструкция.html.

ПЕРЕД ОБНОВЛЕНИЕМ: экспортируйте JSON в прежней игре.
В новой: настройки → Прогресс → Импорт. Схема сохранения остаётся 8;
это не ошибка и не признак старой игры. Баланс не пересчитывается.

Для обычного запуска ничего устанавливать не нужно.
Дополнительный сервер для телефона требует Python 3 и доверенную локальную сеть.
