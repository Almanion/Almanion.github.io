# Прогресс «Орбитального курьера» в аккаунте Almanion

## Что требуется от владельца сайта

1. Открой [Firebase Console → Realtime Database → Rules](https://console.firebase.google.com/project/almanion-70120/database/almanion-70120-default-rtdb/rules).
2. Сохрани текущие правила отдельно. Замени весь текст правил содержимым [firebase/database.rules.json](../../../firebase/database.rules.json) из этой версии репозитория и нажми **Publish**. Файл включает прежние правила сайта и новый раздел gameProgress; не заменяй всё только новым разделом.
3. Никакие ключи, пароли или новые способы входа добавлять не требуется. Публикация сайта в GitHub Pages сама по себе правила Firebase не обновляет.

## Первое подключение

1. На устройстве с нужным прогрессом сначала сделай **Настройки → Прогресс → Экспорт** и сохрани JSON.
2. Войди в свой обычный аккаунт на [главной Almanion](https://almanion.github.io/).
3. Открой [игру](https://almanion.github.io/games/orbital-courier/), нажми **На устройстве → Подключить аккаунт**. Дождись статуса **В облаке**.
4. На втором устройстве войди в тот же аккаунт и также подключи облако. Пустой профиль загрузит облачную копию автоматически; если обе копии уже содержат прогресс, игра предложит выбрать.
5. Для проверки пройди контракт или купи доступное улучшение на первом устройстве, дождись **В облаке**, затем на втором открой окно аккаунта и нажми **Проверить сейчас**. Сверь контракты, баланс и оборудование.

Обе страницы должны быть на одном адресе сайта (almanion.github.io). Firebase хранит вход отдельно для каждого домена: [документация Firebase](https://firebase.google.com/docs/auth/web/auth-state-persistence).

## Если копии различаются

Выбор применяется ко всему профилю: деньги, покупки, чеки, курсы, достижения и настройки не складываются. Сравни сведения **На устройстве** и **В аккаунте**, затем выбери нужную копию. Перед заменой сохраняются обе версии; хранятся три последние пары.

**Резервные копии ↓** позволяет скачать любой из этих JSON. Для восстановления отключи облако, импортируй JSON через Настройки → Прогресс → Импорт, затем подключи облако и при конфликте выбери местную версию. Экспортированные копии храни отдельно от браузера: очистка его данных удалит и местный резерв.

Во время рейса и его разбора чужая версия не загружается. Для загрузки вернись к подготовке через **Ещё раз**. Изменения проверяются при сохранении, возврате к вкладке и примерно каждые 30 секунд, пока вкладка видима. При пропавшей связи игра сохраняет прогресс локально; повторить отправку можно кнопкой **Проверить сейчас**. Не закрывай вкладку до **В облаке**, если переходишь на другое устройство.

При смене аккаунта игра требует явного выбора: автоматического переноса между аккаунтами нет. Отключение облака оставляет местный прогресс. Обычная игра из автономного HTML работает без аккаунта.

## Устройство синхронизации

Копия находится в gameProgress/UID/orbitalCourier. Доступ даётся только вошедшему владельцу UID; анонимный вход и другие пользователи не имеют доступа. Владелец сайта не получает отдельного доступа к чужим игровым профилям через клиентские правила. Данные сохраняются целиком с номером ревизии; [транзакция Firebase](https://firebase.google.com/docs/database/web/read-and-write#save_data_as_transactions) отклоняет запись поверх изменившейся копии. Формат игрового профиля остаётся 8, ключ localStorage — orbital-courier-save-v8.

Это перенос личного прогресса, без рейтинга и серверной проверки честности заработка. Настоящий вход и перенос через рабочую базу нужно проверить после публикации правил; локальный эмулятор и подставной транспорт не доказывают настройку рабочего проекта.
