# Орбитальный курьер 9 — отчёт о проверке

## Что проверялось
Выпуск **9.0 «На связи, пилот»**. Текущий итоговый переносимый HTML собран из тех же исходников, что находятся в архиве. Изменялись интерфейс и ввод, а не уровни/экономика. Контрольные курсы использовались для регрессии; это не прохождение независимыми игроками.

Среда: **Chromium 144.0.7559.96 built on Debian GNU/Linux 13 (trixie)**, Node.js **v22.16.0**, Python + Playwright. Проверка экрана выполнялась в headless Chromium. Запуск страниц через сетевые адреса и file: ограничен политикой управляемого браузера, поэтому использовался `page.set_content` с полным собранным документом. Для сценариев профиля явно предоставлено хранилище в памяти. Оно не доказывает долговременную сохранность браузерного профиля.

## Прогон кампании
Все **80 карт** пройдены в обычном режиме через рабочий цикл кадров итоговой игры. В дополнение выполнены ветви B всех **12 вариативных карт**: всего 92 завершённых рейса этой группы. Все 16 новых/изменённых в v8 карт и их альтернативные ветви проверены в PRO: ещё 28 рейсов. Дополнительно повторные рейсы проверяют отсутствие повторного начисления и воспроизведение истории.

Прогон использует известные авторские решения и ускоренный показ. Он проверяет интеграцию, а не сложность поиска курса человеком. Модель движения и шаг физики не изменялись. Высокий множитель времени в некоторых диагностических снимках — параметр теста, а не новая предлагаемая кнопка игры.

## Экраны и доступность элементов

## Что проверено по управлению
- Запятая, отрицательный угол, неверный ввод, минимумы и максимумы; Enter не запускает рейс.
- Крупные кнопки, одиночный шаг без удвоения, удержание и его отмена отпусканием/уходом/отменой указателя.
- Курс и обзор, колесо, Alt + мышь; простой клик не меняет прицел.
- События CDP Touch: начало прицеливания первым пальцем, откат при появлении второго, изменение масштаба, продолжение оставшегося пальца без случайной доводки.
- Первое нажатие запуска при активном числовом редакторе завершает ввод. Уменьшенная область экрана имитирует клавиатуру; это не реальная клавиатура телефона.
- Временная пауза в панели маршрута, возобновление, подтверждение повтора, потеря фокуса.
- Нормальный и сокращённый переходы, повторная команда не пропускает уровень; физика до старта не идёт.
- Фокус Tab / Shift+Tab внутри диалога, Escape и возврат к открывшей кнопке; доступное закрытие длинного окна.
- Память A/B, запись результата, ползунок времени, сравнение; начисление от просмотра отсутствует.

## Что проверено по данным и другим экранам
Перенос действительного v8-профиля, совпадение денег/опыта/чеков/рекордов/курсов; экспорт JSON, отмена импорта, подтверждение импорта, отклонение повреждённого JSON. Это происходило с фикстурой хранилища в памяти. Проверены запрет хранилища и доступный значок предупреждения, а не молчаливая потеря прогресса.

Покупка требует подтверждения, отмена не списывает средства, возврат идёт по чеку. Выбор хвоста не списывает XP. В каталоге работает поиск; в наградах отображаются 93 достижения. Проверены вкладки настроек и защита удаления профиля словом «СБРОС».

## Что исправлено в ходе этого выпуска
Выделен независимый от прокрутки запуск; устранено переполнение заголовка каталога на узком экране. Исправлены утечка фокуса из диалога, риск двойного шага кнопки, запуск после потери фокуса поля при касании, остаточный жест после масштабирования, устаревшая оценка высоты после поворота экрана. Повтор и незаконченный рейс разделены подтверждением. Просмотр записи обозначен как запись, а не текущая успешная доставка.

## Не проверено / не обещается
**Физические Android/iPhone, Safari, реальная экранная клавиатура, долговременное localStorage, установка как приложение, полная доступность экранному диктору, сеть с настоящим телефоном и независимый UX-тест людьми не проверялись.** Разрешённый сценарий Fullscreen API заблокирован политикой среды: проверен только безопасный отказ. Это не утверждение о работе во всех браузерах или об отсутствии любых ошибок.

## Воспроизведение
`npm test` — ядро и статическая проверка. `npm run test:browser` — оба сценарных файла Playwright. Нужен установленный Chromium в PATH и Python-пакет playwright. Для обычной игры эти инструменты не нужны.

Исходные результаты: `core-results-v9.json`, `static-results-v9.json`, `browser-results-v9.json`, `browser-edge-results-v9.json`, соответствующие журналы. Снимки v9 — `screenshots-v9/`; диаграммы прежних уровней в `screenshots-v8/` не являются снимками нового интерфейса.
