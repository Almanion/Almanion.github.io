# Архитектура версии 9

## Разделение ответственности

| Файл | Назначение |
|---|---|
| `index.html` | Семантическая структура страниц, пульта, карты, диалогов |
| `src/legacy.css` | Базовое оформление прежних страниц внутри слоя `legacy`; без конкурирующих `!important` |
| `src/interface-v9.css` | Текущая адаптивная компоновка, пульт, диалоги, телефоны и планшеты |
| `src/interface-v9.js` | Единый контроллер мыши/касания/клавиатуры, поля ввода, камера, модальные панели, жизненный цикл интерфейса |
| `src/ui-v8.js` | Существующие представления маршрутов, наград, настроек и результата; геометрия и ввод делегированы UI9 |
| `src/game.js` | Состояние приложения, цикл кадров, запуск/повтор, действия страниц, сохранение |
| `src/renderer.js` | Canvas-рисование; координаты камеры не возвращаются в физику |
| `src/physics.js` | Детерминированное движение, порталы, груз, столкновения и доставка |
| `src/levels.js`, `src/routes.js` | 80 карт, требования и независимые ветви в одном мире |
| `src/medals.js`, `src/economy.js`, `src/progression.js` | Медали, цены, начисления, профиль и миграции |
| `src/achievements.js`, `src/cosmetics.js`, `src/audio.js` | Достижения, визуальные хвосты, синтез звука |
| `src/flight-review.js` | Запись уже выполненного полёта и сравнение прошлых попыток |

Физические модули и правила экономики из v8 сохранены побайтово. Проверка: `docs/unchanged-v8-v9.json` и `tests/ui9.static.cjs`. Старый номер в имени `ui-v8.js` означает происхождение представлений, не версию выпущенного приложения.

## Поток данных

`Пользователь → UI9 → проверка ввода → App.setAim / действие → симуляция → отрисовка + компактная телеметрия`.

Камера, открытый диалог и масштаб не изменяют угол/скорость, если активен режим обзора. Числовые поля не создают отдельную копию состояния. План и память курсов физически перемещаются в диалог, затем возвращаются.

## Сборка
`node tools/build.cjs` встраивает связанные CSS и JS в `Orbital Courier.html`. Исходный `index.html` и переносимый файл используют один код. Проверяется побайтовое совпадение итоговой сборки с шаблоном и исходниками. Нет сборщика пакетов, загрузки ресурсов по сети или CDN.

## Инварианты
Вариант маршрута не меняет геометрию; портал сохраняет скорость; доставка по адресам не останавливает капсулу. Награды начисляет только завершение живой симуляции. Обзор/перемотка/переключение UI ничего не начисляют. Повторные рекорды не дают повторную полную выплату. Новая версия приложения сохраняет схему JSON 8, чтобы не создавать ненужную миграцию данных.

Детали модели движения и уровней — в `LEVEL_DESIGN.md` и исходниках. Архив архитектуры v8 — в `history/`.
