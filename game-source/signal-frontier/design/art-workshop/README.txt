МАСТЕРСКАЯ ГРАФИКИ SIGNAL FRONTIER

Открыть: двойной щелчок по Open-Workshop.cmd в этой папке.
Адрес по умолчанию: http://127.0.0.1:4270
Требуется установленный Node.js 20 или новее (в текущем окружении уже есть).
Ярлык запускает локальный сервис скрыто или использует уже запущенный.
Сервис работает, пока включён компьютер. После перезагрузки используйте ярлык снова.

КАК ПОЛЬЗОВАТЬСЯ
1. Выберите объект в каталоге. Начальный набор доступен отдельным фильтром.
2. Скопируйте полный промпт. Скачайте и приложите указанный референс.
3. Создайте изображение в выбранной нейросети.
4. Перетащите результат в мастерскую, выберите файл либо вставьте картинку из буфера.
5. Загрузите другие варианты при необходимости, откройте их крупно и нажмите «Выбрать вариант».
6. При необходимости добавьте заметку и сохраните её отдельной кнопкой.

Выбор означает «взять этот файл для дальнейшей работы». Саму игру он не изменяет.
Референсы уже предоставлены: исходные модели, объекты карты, палитра, значки и игровая сцена.
Для новых моделей камера задана явно: 65° над землёй, 25° от вертикали.
Схема camera-guide.png доступна возле промпта. Низкую камеру старого предметного
референса повторять не нужно; он задаёт назначение и компоновку. Варианты состояний
используют уже выбранную модель в высоком ракурсе.
Камера также зафиксирована по направлению: без обхода сбоку и крена. Базовое здание
показано входом строго вниз, передняя граница площадки горизонтальна; у бойцов базовое
направление вправо. Только отдельные задачи PREP-turn поворачивают здание на 90/180/270°.
Для новых текстур и простых знаков референс необязателен — об этом написано в задании.
После выбора новой модели она автоматически используется в связанных карточках и состояниях.
В повторяемом задании можно выбрать здание. Правки готового результата (например, вырез фона)
становятся доступны после загрузки и выбора исходного изображения в основном задании.
Для каждого промпта выбран один вариант; все остальные сохраняются.
Архив обратим: оригиналы не удаляются, вариант можно вернуть.
Мастерская принимает статические PNG, JPEG и WebP до 32 МиБ / 40 мегапикселей.
Само изображение не пересжимается. Маленькое отдельное превью нужно только интерфейсу.
Дубликат определяется по содержимому файла внутри одного промпта.

ГДЕ ФАЙЛЫ
Постоянная папка по умолчанию:
  %USERPROFILE%\Documents\ChatGPT\Signal-Frontier-Art-Library
Она находится вне временной рабочей копии проекта и не публикуется на GitHub Pages.
Точный путь также виден в кнопке «Где хранятся файлы».

  files/<PROMPT-ID>/<UUID>.<png|jpg|webp> — неизменённый оригинал;
  files/<PROMPT-ID>/<UUID>.prompt.txt — текст каталога на момент загрузки;
  previews/ — небольшие превью для сайта;
  library.json — основная библиотека, выбранные варианты, заметки и контрольные суммы;
  library.json.backup — предыдущая успешно сохранённая версия библиотеки;
  selected.json — список выбранных изображений с абсолютными путями;
  workshop.log — журнал запуска.

ДЛЯ ПОСЛЕДУЮЩЕЙ РАБОТЫ АССИСТЕНТА
Читать selected.json, затем сверять revision с library.json: основной источник — library.json.
Индекс selected.json восстанавливается при запуске сервиса. Через API /api/selected он
всегда формируется из текущей основной библиотеки. SHA256 позволяет проверить оригинал.
prompt.txt хранит текст каталога, а не доказательство точного промпта во внешней нейросети.
Перед интеграцией проверить качество, альфа-канал, ракурс, габарит, исходную лицензию
и выбранный тип. Не брать вариант из архива и не подменять оригинал его превью.
Не считать выбранную картинку уже внедрённой в игру.
Копировать в сборку только подготовленные и проверенные ресурсы отдельным обновлением.

ДЛЯ ЗАПУСКА И ПРОВЕРКИ
Из корня репозитория:
  node tools/signal-art-workshop.js --start
Для запуска в текущем терминале:
  node tools/signal-art-workshop.js --port 4270
Для отдельной тестовой библиотеки:
  node tools/signal-art-workshop.js --port 4271 --data-dir C:\path\to\test-library

Сервер слушает только 127.0.0.1. Внешние сервисы и облачное хранилище не используются.
Доступ к файлам ограничен каталогом референсов и библиотекой изображений.
Сайт, его сервер и загруженные данные не включаются в публичную сборку игры.
Не удаляйте постоянную папку библиотеки при очистке рабочей копии.
